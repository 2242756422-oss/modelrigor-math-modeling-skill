# ModelRigor Change Log

## v5.1.2 — 2026-10-26 (ModelRigor Public Open-Source Release)

- Rebranded project identity to **ModelRigor** (`modelrigor`): Research-Grade Mathematical Modeling & Verified Scientific Computing.
- Preserved full mature mathematical modeling architecture: question-first modeling, domain P0 gates, dual freeze (Scientific Freeze & Research Freeze), result registries, evidence promotion, and publication figure review.
- Ensured zero hard dependency on private maintainer paths; graceful native Matplotlib fallback when external legacy plotting libraries are absent.
- Standardized open-source packaging, MIT license, GitHub Actions CI workflow, and bilingual (English and Chinese) documentation.
- Independent verification and audit hardening: Python actual argv entry binding, process exit fact separation from provenance status, raster/vector image validation, and fail-closed integrity regressions.
- Documentation & User Experience Optimization:
  - Systematically structured six core differentiators (Mechanism-first, Real computation, Dual-freeze architecture, Whole-problem orchestration, Publication-grade scientific visualization, and Complete closed-loop workflow).
  - Integrated 7-stage research workflow infographic (`assets/modelrigor-workflow.png`) with matching architectural diagrams.
  - Added fast 3-minute quick-start guide, three real-world use scenarios (Contest, Solver-only, Independent Audit), and comprehensive FAQ section.


## v5.1.1 — targeted document/provenance fixes and modeling depth

- Shared content-keyed DOCX/PDF/text extraction and page-specific PDF locators; partial/image-only PDFs cannot claim completed text review. Final page gate accepts and binds the actual submitted PDF as well as DOCX.
- Source nature separates computed, analytical, observed, given and demo results; production receipt versus reviewed derivation versus original provenance enforced without pointless analytical runs.
- Current scientific snapshot can be reused for four scientific acceptance dimensions, not visual/content judgments; substantive Claim changes and registry/source/argument dependencies receive scientific impact routing.
- Resource adapter no longer restores administrative ledgers in efficient mode; optional legacy plotting absence exercises real native Matplotlib fallback.
- Existing domain/development/visual protocols strengthen mechanism-to-model derivation, justified innovation, structural result analysis and science-first figure design without new score/state files.
- Controlled conservative two-compartment case checks derivation, positivity, weighted mass, valid assumptions, structural repair, refinement and identifiability; numeric, figure and DOCX/PDF evidence remain explicitly limited examples.

## v5.1.0 — research quality and efficient execution

- Exact source transcription and source-derived display rounding; real execution assertions / reviewed arguments instead of PASS-only verification.
- Benchmark winner, means, gap, direction and run output reproduced; invalid/failed runs cannot silently vanish. Optimality obligations derive from actual task; legal positive gap cannot certify an exact optimum.
- Adaptive discipline checks, staged creation, result-centered dependency graph, source-derived numeric map and one substantive acceptance review; legacy layouts remain compatible.
- Actual image/final-size review, blank-image rejection, required-visual binding, candidate selection/merge with declined candidates exempt from production obligations.
- Whole-paper panel/task inventory remains PENDING until actual portfolio review; annual official-rule/delivery checks and honest package/full-layout verification scopes.
- Core scientific snapshots retained, incremental impact and presentation-only separation; ordinary paper edits do not rerun verified experiments.
- Regression fixtures explicitly separated from actual scientific/visual/competitive judgments; historical reports retained, not rewritten into imaginary PASS records.

## v5.0.5 — KEY_DECISION_ONLY collaboration mode

- Added optional `KEY_DECISION_ONLY -> external execution -> RETURN_AUDIT` workflow.
- Full research workflow remains unchanged and available.
- Stage A emits one compact executable decision packet and stops before heavy implementation.
- Stage B uses targeted high-risk verification first, then preserves all original v5 final gates and five reviewer roles.
- Added templates for `QUESTION_DECISION_PACKET.md` and `EXECUTION_RETURN.md`.
- No page/figure/formula quotas, no reduced reasoning requirement, and no automatic weakening of Result Truth.

# v5.0 Changelog

- 将Domain Professionalism提升为Solver前P0，新增14问Domain Map、题型Model Ladder和Literature-to-Model映射。
- 分离Scientific Freeze与Research Freeze，增加REOPEN_FOR_DEVELOPMENT及科学/展示版本STALE传播。
- 分离官方硬页限和竞争内容充分性，删除Depth到Page/Figure/Table/Formula/Benchmark/Ablation的活动规则。
- 新增Evidence Promotion、Content Units、Table Portfolio、Visual Role Coverage、Monotony和Word页面hash QA。
- Result Registry采用typed locator和artifact hash；analytical真值从结构化pointer读取，verification复核观测值和科学版本；required output必须由批准结果/主张覆盖。
- Benchmark先公平性后排名，小于tolerance为PRACTICAL_TIE；混合贡献主张条件触发Ablation。
- Verification由uncertainty/error budget的主风险驱动。
- 七质量维度独立判定，五审稿角色要求独立运行来源。
- Freeze manifest采用精确工件集、scientific claim digest和幂等版本；科学变更传播下游STALE，Research Freeze后篡改可检出。
- 新增可执行全文audit-paper、全量paper numeric map、合法REOPEN，以及绑定renderer manifest与逐页review JSON的真实DOCX/A4回归。
- 重写schema、integrity和正反向回归；固定物理反演旧稿与匿名副本行为一致，并设改善反事实。
- `cumcm-step-review`仅作只读资源，真实API烟雾测试；隔离演示数据和历史数量政策。
