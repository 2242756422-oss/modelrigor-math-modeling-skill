# 科研图表开发

建模阶段规划视觉问题：关系/机制、结果/创新、关键验证、决策解释。保留广泛机会挖掘，candidate不是必画图。mine_visual_opportunities提供稳定ID，一份selection计划SELECT/DECLINE/MERGE/DEFER；拒绝候选只需科学理由，无数据绑定/生成义务。同角色可有不同任务；不按图数、九宫格或图型多样性配额。
机制/几何/流程用可编辑SVG/draw.io；物理场、响应面、轨迹用真实求解数据；仿真/示意/合成明确标注。不能用AI生图冒充仿真或实测。AI概念图必须核查科学关系并标示示意。
实际路径：科学目的与信息损失 → 验证来源/统计定义 → 图形编码与单/多panel架构 → 真实生成 → 打开图像 → 记录观察并定向修复 → 最终论文尺寸与A4查看。不能根据文件存在、hash、图注或候选字段断言质量。正式图需plot_code/vector源、输入/输出绑定及visual_review，后者记录实际观察、审查人、最终宽度/预览。无观察不通过。
正式图另绑定generation_receipt：真实绘图/导出执行，输入包含已登记数据源，代码/可编辑源与输出图一致；不能拿“有源代码”当作已经运行。一个回执可绑定多张同一次生成的图，不重复填写。简单物理关系可用有实质依据的推导或已有图解释机制，研究验收明确mechanism_equivalence；题目明确要求的VISUAL输出仍必须交付。
科学检查数据准确、聚合/不确定性、尺度/截断、单位、claim匹配；视觉检查层次/密度/编码、字体/字号/线宽/marker、轴/legend/colorbar、panel a/b/c、图题、白底/留白和最终可读性。同构panel共享适用尺度与legend；合并损害可读性则分开。物理3D仅空间关系有用时，不一刀切；定性图有明确示意边界。
颜色随任务选择，顺序/发散/分类编码合语义、色盲/灰度可读；同一实体跨问稳定，不机械固定palette。阅读科学可视化cookbook与只读chart selection/plot_style/figure_audit成熟资源；资源演示数字隔离。
一个图例错误仅修该图/该legend。已满足科学/视觉要求不反复无目的精修。逐问只查核心机制、当前结论证据、无用图和基本规范；全面Portfolio/视觉节奏仅在全部正文完成后执行。

自动检查分三层：文件可解码和来源绑定；实际显示尺寸下的采样/渲染；实质科学与视觉判断。栅格按`final_width_mm`及可选`final_height_mm`算双向有效DPI；无高度时按原图比例，实际页面须复核伸缩。线条/文字印刷默认以300 DPI作参考，连续图像、电子用途或小示意可在现有visual_review的`raster_requirement`注明`minimum_effective_dpi`及`basis`，由实际最终尺寸观察裁决，不把像素量当学术质量。无尺寸不假装可读。SVG/PDF验证文件与实际预览，不套栅格源像素阈值；最终尺寸检查字体替换、裁切、布局和嵌入栅格。300×200不是统一准入标准，高清也不能豁免数据真源或真实审图。复用现有最终页面QA，不另建图表评分系统。

制作时以数据结构裁决：连续有序量用顺序色标、零点/基准两侧用发散色标、无序类别用离散编码；相同颜色不表示不同含义，不用分类色伪造连续场。不同单位不共用无解释轴，必要时独立panel或有依据的无量纲量；log轴/非零起点/截断要可解释且标清，误差条说明SD/SE/CI/分位和比较单位。不存在相应数据时不画精确曲线/误差带；插值、平滑与场重建明确方法及边界，不改统计结论。3D只为真实空间结构，不掩盖简单关系。

panel围绕一个科学论点组织任务：机制/关系、主结果、针对性验证或解释可组合；同构图共享适当尺度/legend，异构图不强行统一单位，拥挤就拆。场图提供真实求解网格、边界与colorbar，示意图清楚区分非定量性质；流程图不能代替关键推导。图前指出要回答的科学问题，图后联系方程/约束解释机制、例外和可信范围。现有visual_review记录实际判断，不新建图表创新评分。
