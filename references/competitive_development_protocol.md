# 研究成果验收

Scientific Freeze后仍需深度解释、有效图表和完整正文；“可复现”不代表“优秀竞赛论文”。Research Freeze保留原命令/状态兼容，其新语义为成果验收，不再逐问复制整套最终审稿。
一次research_review实际阅读本问正文、结果与图；七质量维度可引用已完成core_review，不重复科学分析。每项结论必须有具体reasoning与可定位证据，重大未决项阻断。程序检查输出覆盖/格式，不能从CSV条目数或evidence_locator推断论证充分。
检查真正回答题目、关键推导可重建、方法匹配结构、结果有解释与边界、公式有任务、图前引导/图后分析、跨问新增结构已表达。简单验证可并结果分析，不写通用算法小论文；模型评价/推广通常全文末尾统一。
只按风险触发专业攻击；不制造五份名义独立报告。Peer Gap为明确方法缺陷/创新/竞争主张服务，无必要不强制同题论文比厚度。已有图/数值达标保持；单点问题单点修复。全文完成后集中严格审查研究、图表组合和竞争叙事。

科研叙事沿“难点 → 主要数学思路 → 建模/推导 → 求解/验证 → 结果含义与边界”连续展开，不拼接几个独立算法。正文与真实实现双向核查：不能省掉重要推导，也不能写程序未使用的复杂公式/约束。关键创新说明为什么需要、为何成立及实际收益，使用成熟方法不包装成理论突破。

结果分析从方程、活跃约束、辨识与误差出发解释趋势，必要时看边际变化、临界区、交互、权衡和实际意义；区分推导结论、数值观察、经验解释与待验证机制。单条曲线不证明普遍性，相关不当因果，未计算的机制不写确定结论。图后分析解释结构与可信范围，不重复读数。

已有assessments中四个科学维度可用`{"outcome":"ACCEPTED","reuse":"CURRENT_SCIENTIFIC_FREEZE"}`引用当前已审核科学快照，不重填reasoning/evidence；程序仍完整核快照及科学依赖。VISUAL_QUALITY/CONTENT_DEPTH/COMPETITIVE_QUALITY不能如此豁免，检查本次新增表达与实际图。纯图例/措辞修改保留科学引用；控制方程、核心数据、参数、求解或Claim强度变动重核相关科学链。此机制复用真实判断，不将旧PASS升级为新证明。
